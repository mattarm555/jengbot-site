Privacy policy

Last updated November 23, 2026

JengBot stores only what its features need to work. It never reads the content of your messages, and it doesn't sell or share data for advertising.

What JengBot stores

About servers

  • The server’s ID and name, and whether JengBot is still in it.
  • The settings you choose (welcome, moderation, tickets, XP, role panels), including channel and role IDs.
  • The server’s plan: Premium grants, and Discord subscription records if you subscribe through Discord.

About members

  • Moderation cases: the user ID and username of the member and the moderator, the action, the reason, and when it happened.
  • Tickets: the opener’s user ID and username, the subject, who closed it, the reason, and when. Messages sent inside a ticket are not stored.
  • XP: user ID, username, XP total, level, how many messages earned XP, and when XP was last earned. JengBot sees that a message was sent, never what it says.
  • Newcomer insights: for members who join while it’s on, the user ID and when they joined, first sent a message, last sent a message (noted at most every few hours) and left. Server staff only see totals and percentages. Staff can turn this off on the dashboard. These records are deleted after 180 days.
  • Weekly report: which weeks a report was posted, so it’s never sent twice. The report itself only contains totals, never names.

When you log in to the dashboard

  • Your Discord user ID, username and avatar, and a Discord access token limited to reading your profile and your server list. It’s used to show which servers you can manage.
  • One login cookie. Sessions end after at most 7 days, or when you log out.
  • No analytics, tracking or advertising cookies.

Why

Only to run the features you turn on: greeting members, recording moderation cases, running tickets and levels, and checking who may change a server’s settings. The bot’s operational logs can contain IDs and are used only to fix problems.

Who else handles it

  • Discord, where the bot runs. Discord’s own privacy policy covers your Discord account.
  • Supabase, which hosts the database (encrypted connections, United States).
  • The website host serving these pages, which, like any website, sees visitors’ IP addresses in its logs.

Nothing is sold, rented or shared for advertising.

How long it’s kept, and deleting it

Data is kept while JengBot is in your server, except newcomer insights, which are deleted after 180 days. If you remove JengBot, your settings are kept so they come back if you add it again.

  • Server owners can ask for all of a server’s data to be deleted.
  • Members can ask for their own data (XP, and their name in moderation cases and tickets) to be deleted or exported. A server’s staff can also reset a member’s XP at any time.

Ask in the support server. Requests are handled within 30 days.

Age

JengBot is for Discord users, who must meet Discord’s minimum age (13 in most countries).

Changes

If this policy changes, the date above changes, and significant changes are announced in the support server. See also the terms.
